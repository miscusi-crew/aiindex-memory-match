# Memory Match

Flip cards and find all the pairs in as few moves as you can.

Turn over two cards at a time. Matching pairs stay face up. Clear the board in as few moves as you can.

- Three board sizes, from 6 to 12 pairs
- Your best result per size is saved on this device

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
